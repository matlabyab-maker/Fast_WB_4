# Fast_WB_4 — مرورگر اندروید

پروژهٔ سادهٔ Android با شناسهٔ `com.fastm.browser`، Java 17، Android Gradle Plugin 8.5.0، Gradle 8.7 و AndroidX WebKit 1.12.1. رابط کاربری در Java ساخته شده و فایل layout XML ندارد.

## امکانات

- WebView، نوار نشانی/جست‌وجو، بارگذاری HTTPS پیش‌فرض، رفت‌وبرگشت، Enter/بازخوانی، خانه و برگهٔ تازه (`about:blank`).
- انتخاب فایل برای فرم‌های وب، بازکردن لینک‌های HTTP/HTTPS، اشتراک URL، کپی/چسباندن، حالت User-Agent دسکتاپ/موبایل.
- علاقه‌مندی‌ها با ذخیرهٔ محلی، دریافت‌ها از طریق برنامهٔ دریافت‌کنندهٔ سیستم و ذخیرهٔ صفحه به Web Archive محلی و اشتراک آن.
- دکمهٔ IP Set بلافاصله سمت راست Save: تنظیم Proxy Port، پیکربندی/خروجی Vray، پروفایل/خروجی Tunnel و تنظیم دستی Private DNS.

## ساخت محلی

نیازمند JDK 17 و Android SDK با platform 34 است:

```sh
gradle assembleDebug
```

APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## بارگذاری با MGit و دریافت APK از GitHub Actions

1. در GitHub یک مخزن خالی بسازید. در MGit گزینهٔ Clone را بزنید و نشانی مخزن را وارد کنید؛ برای مخزن خصوصی از روش احراز هویت پشتیبانی‌شده در نسخهٔ MGit خود استفاده کنید.
2. فایل‌های این پروژه را در پوشهٔ مخزن قرار دهید (یا ZIP را بیرون از MGit استخراج و محتویات پروژه را در پوشهٔ مخزن کپی کنید). مطمئن شوید `.github/workflows/android.yml` نیز کپی شده است.
3. در MGit، تغییرات را Stage کنید، Commit بسازید و Push کنید. برای مخزن تازه، اگر لازم بود شاخهٔ پیش‌فرض را `main` تنظیم کنید.
4. در GitHub به تب **Actions** بروید و اجرای **Android build** را باز کنید. Workflow با JDK Temurin 17 و Gradle 8.7 دستور `gradle assembleDebug` را اجرا می‌کند.
5. پس از موفقیت، در پایین صفحهٔ اجرای workflow، artifact با نام **Fast_WB_4-debug-apk** را دانلود و استخراج کنید؛ فایل `app-debug.apk` را روی دستگاه نصب کنید. نصب از منبع ناشناس ممکن است نیازمند اجازهٔ Android باشد.

## تنظیمات و محدودیت‌های مهم

- **Proxy:** برنامه تلاش می‌کند AndroidX WebKit `ProxyController` را برای WebView به کار گیرد؛ اعمال آن به پشتیبانی نسخهٔ WebView وابسته است. وقتی قابلیت در دسترس نباشد، برنامه فقط مقدار را ذخیره می‌کند و پیام محدودیت می‌دهد. این تنظیم تضمین‌کنندهٔ پراکسی برای سایر برنامه‌ها یا تمام ترافیک دستگاه نیست.
- **Vray:** هستهٔ V2Ray/Xray در این پروژه وجود ندارد. متن یا لینک ذخیره‌شده فقط با ACTION_SEND به برنامهٔ سازگارِ نصب‌شده صادر می‌شود؛ اجرای پروتکل در خود مرورگر ادعا نمی‌شود.
- **Tunnel:** این پروژه کلاینت یا هستهٔ OpenVPN/WireGuard ندارد. پروفایل به برنامهٔ VPN سازگار صادر می‌شود؛ اتصال واقعی وابسته به آن برنامه و تأیید کاربر در Android VPN است.
- **DNS:** hostname فقط ذخیره یا کپی می‌شود. کاربر باید Private DNS سیستم را دستی تنظیم کند؛ برنامه نمی‌تواند DNS سراسری Android را بی‌صدا تغییر دهد. اگر صفحهٔ تنظیمات اختصاصی در دستگاه موجود نباشد، تنظیمات Wireless باز می‌شود.
- ذخیرهٔ Web Archive به فایل خصوصی برنامه انجام می‌شود؛ حذف داده‌های برنامه، فایل‌های ذخیره‌شده را نیز پاک می‌کند. دریافت‌های وب با Intent به برنامهٔ دریافت/مرورگر سازگار سپرده می‌شوند.
- پروژه به شبکهٔ اینترنت برای دریافت وابستگی‌های Gradle و اجرای workflow نیاز دارد. مجوز ذخیره‌سازی عمومی درخواست نمی‌شود.
